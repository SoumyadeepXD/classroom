# Backend API Internal Documentation (`backend/api/docs/`)

## 1. Purpose of the Directory
This directory serves as a repository for internal backend engineering notes, profiling results, profiling benchmarks, and developer setup checklists specific to the Spring Boot service.

## 2. What Belongs Here
* Framework-specific setup instructions and profiling reports.
* Internal notes regarding Spring Boot profiles, Actuator configurations, and JVM tuning.
* Dependency evaluation records.

## 3. What Does NOT Belong Here
* Formal public API contracts (belongs in `docs/05-api/`).
* High-level architectural specifications (belongs in `docs/03-architecture/`).
