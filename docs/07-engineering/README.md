# Engineering Standards & Guidelines (`docs/07-engineering/`)

This directory establishes engineering rules, coding conventions, testing methodologies, git practices, error handling conventions, and observability standards for the Classroom Platform repository.

## Contents

1. [**coding-standards.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/07-engineering/coding-standards.md): Code style, static analysis rules, naming conventions, and linting standards.
2. [**testing-strategy.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/07-engineering/testing-strategy.md): Testing pyramid, unit, integration, API contract, performance, and WebRTC testing models.
3. [**git-workflow.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/07-engineering/git-workflow.md): Branching policies, conventional commits, pull request review gates, and release tagging.
4. [**error-handling.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/07-engineering/error-handling.md): Unified error taxonomy, exception handling in Spring Boot and React, and error codes.
5. [**logging.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/07-engineering/logging.md): Structured JSON logging formats, correlation IDs, and PII masking policies.
6. [**observability.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/07-engineering/observability.md): Prometheus metrics, Grafana dashboards, OpenTelemetry distributed tracing, and alerting thresholds.
