# Deployment & Operations Runbooks (`docs/08-deployment/`)

This directory documents deployment runbooks, local development workflows, containerization strategies, production environment configurations, self-hosting setups, and disaster recovery procedures for the Classroom Platform.

## Contents

1. [**local-development.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/08-deployment/local-development.md): Architectural prerequisites and local multi-service orchestration blueprints.
2. [**docker.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/08-deployment/docker.md): Container build strategies, multi-stage compilation blueprints, and base image specifications.
3. [**environments.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/08-deployment/environments.md): Environment differentiation and parameter matrices (Development, Staging, Production).
4. [**production.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/08-deployment/production.md): Enterprise cloud deployment topology, autoscaling, ingress routing, and TLS hardening.
5. [**self-hosting.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/08-deployment/self-hosting.md): Runbook for deploying a self-contained, on-premises or air-gapped instance of Classroom Platform.
6. [**monitoring.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/08-deployment/monitoring.md): Observability deployment guide covering Prometheus, Grafana, and alert paging.
7. [**backup-recovery.md**](file:///Users/soumyadeepxd/Developer/classroom/docs/08-deployment/backup-recovery.md): Backup automation, Point-in-Time Recovery (PITR), and disaster recovery validation procedures.
